## House rules for agents

1. **Ports:** check the port map below before binding. Bind to `127.0.0.1` unless something off the machine needs the service. Never take a port that is already listed.
2. **Reuse the shared AI services** (next section) instead of starting another model server. Use them, but never restart, reconfigure or upgrade them. Loading a different model into Lemonade evicts the one the other services use.
3. **Docker:**
   - Use compose, with an explicit `name:`.
   - Pin every image to a version tag, ideally with its digest. Never `:latest`.
   - Tag your own builds with their git commit.
   - Use `restart: unless-stopped` for anything meant to stay up.
   - Never stop, remove or prune containers, images or volumes you did not create. Several projects share this engine, including the owner's GitHub Actions runners.
4. **Python:** uv only, and nothing installed globally.
   - Each project has a `pyproject.toml`, a committed `uv.lock`, a `.python-version` and its own `.venv`. Build with `uv sync --locked`; run with `uv run --locked`.
   - In `pyproject.toml`, under `[tool.uv]`, set `python-preference = "only-managed"` and `exclude-newer = "7 days"`. No package version under a week old (supply-chain cooldown), except for a documented security fix.
   - Anything that runs unattended (a service, scheduled task or watchdog) names its interpreter by absolute path, never a bare `python`.
   - Leave `miniforge3\envs\ryzen-ai-py312` alone: it runs the speech-to-text service and breaks easily.
5. **Node:** commit a lockfile (`package-lock.json`, `pnpm-lock.yaml` or `bun.lock`) and install with `ci` or `--frozen-lockfile`. Node is moving from 25 to the 26 line.
6. **Secrets:**
   - Never commit `.env` files or keys.
   - Never put a token in a git remote URL (`https://user:token@…`); use a credential helper. Both mistakes have already been found on this machine and are being cleaned up.
   - Ship a `.env.example` with placeholders instead.
7. **No hand-launched system services.** Anything that must survive a reboot is a decision for the machine's owner. Ask, don't install it.
